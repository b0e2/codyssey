# codyssey-e1-2 · 파이썬 퀴즈 게임 🐍

터미널에서 동작하는 콘솔 퀴즈 게임입니다. 파이썬 문법과 백엔드 기초를 주제로 문항을 카테고리별로 출제하고, 퀴즈와 최고 점수를 JSON 파일에 저장해 프로그램을 종료한 뒤에도 데이터가 유지됩니다.

외부 라이브러리를 사용하지 않고 표준 라이브러리만으로 구현합니다.

## 퀴즈 주제와 선정 이유

주제는 **파이썬 문법과 백엔드 기초**입니다.

파이썬 문법을 고른 이유는 이번 미션에서 배운 내용을 그대로 문제로 옮길 수 있기 때문입니다. 객관식 문항은 정답 하나가 아니라 오답 세 개도 만들어야 하는데, 그럴듯한 오답을 쓰려면 정답의 기준을 정확히 알아야 합니다. 자료형의 차이나 `self`의 역할처럼 안다고 생각했던 개념도 선택지를 만들다 보면 다시 확인하게 됩니다.

백엔드 기초는 앞으로 공부할 방향이라 함께 넣었습니다. HTTP 메서드와 상태 코드, REST, JSON, FastAPI 기초처럼 지식 문항으로 다룰 수 있는 범위만 담았고, 서버나 데이터베이스를 실행하지 않으므로 표준 라이브러리만 사용한다는 제약은 그대로 지켜집니다.

성격이 다른 두 영역을 섞어 출제하면 어느 쪽이 약한지 알 수 없어서 카테고리를 나눴습니다. 원하는 영역만 골라 풀 수 있고, 최고 점수와 기록도 카테고리별로 확인할 수 있습니다.

## 개발 환경

- Python 3.10 이상
- 표준 라이브러리만 사용 (외부 패키지 없음)

## 실행 방법

```bash
# 저장소 복제
git clone https://github.com/<계정>/codyssey-e1-2.git
cd codyssey-e1-2

# 가상환경 (선택, 파이썬 버전을 고정하기 위해 권장)
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 실행
python main.py
```

설치 과정은 없습니다. 파이썬 3.10 이상이면 복제 직후 바로 실행됩니다.

첫 실행 시에는 저장 파일이 없으므로 기본 퀴즈 데이터로 시작하며, 종료 시 프로젝트 루트에 `state.json`이 생성됩니다.

## 기능 목록

메뉴에서 번호를 골라 각 기능을 실행합니다.

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 카테고리·문제 수·출제 순서를 고른 뒤 문제를 풀고 점수를 확인합니다. |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답·카테고리·힌트를 입력해 새 문항을 등록합니다. |
| 3 | 퀴즈 목록 | 등록된 문항을 카테고리별로 묶어 보여줍니다. |
| 4 | 퀴즈 수정 | 문항을 골라 값을 바꿉니다. 빈 입력은 기존 값을 유지합니다. |
| 5 | 퀴즈 삭제 | 문항을 골라 확인 후 삭제합니다. |
| 6 | 점수 확인 | 최고 점수, 카테고리별 최고점, 최근 기록을 보여줍니다. |
| 7 | 종료 | 저장 후 프로그램을 끝냅니다. |

보너스로 다음을 함께 구현했습니다.

- **랜덤 출제 on/off** — 퀴즈 풀기에서 매번 출제 순서(랜덤 / 등록순)를 고릅니다.
- **문제 수 선택** — 풀 문제 개수를 정할 수 있습니다.
- **힌트 + 점수 차감** — 풀이 중 `h`를 입력하면 힌트가 나오고, 그 문항은 정답이어도 배점의 50%만 얻습니다.
- **점수 기록 히스토리** — 회차별 날짜·시간, 카테고리, 푼 문제 수, 점수, 힌트 사용 수를 기록합니다.
- **퀴즈 수정 / 카테고리 분류** — 등록된 문항을 수정하고, 파이썬 문법과 백엔드 기초로 나눠 관리합니다.

프로그램 실행 중 `Ctrl+C`(KeyboardInterrupt)나 입력 종료(EOFError)가 발생해도 비정상 종료 없이 저장 후 안전하게 종료합니다. 저장 파일이 없으면 기본 데이터로 시작하고, 손상된 경우 안내 후 기본 데이터로 복구합니다.

## 카테고리

| 값 | 이름 | 범위 |
| --- | --- | --- |
| `python` | 파이썬 문법 | 자료형, 조건문과 반복문, 함수, 클래스, 예외 처리, 파일 입출력 |
| `backend` | 백엔드 기초 | HTTP 메서드와 상태 코드, REST, JSON, FastAPI 기초, 데이터베이스 개념 |

퀴즈를 풀 때 카테고리 하나를 고르거나 전체를 대상으로 할 수 있고, 문항을 추가할 때도 카테고리를 지정합니다.

## 점수 계산

문항 하나의 배점은 `100 / 총문항수`이며, 최종 점수는 100점 만점으로 반올림합니다. 문제 수를 자유롭게 선택할 수 있으므로 항상 만점 기준을 맞춰 서로 다른 회차의 점수를 비교할 수 있습니다.

힌트를 본 문항은 정답이어도 해당 배점의 50%만 얻습니다.

최고 점수는 두 가지로 관리합니다.

- **전체 최고점** — 카테고리와 무관하게 기록된 가장 높은 점수
- **카테고리별 최고점** — 파이썬 문법, 백엔드 기초 각각의 최고점

카테고리를 "전체"로 선택해 푼 회차는 전체 최고점만 갱신하고, 특정 카테고리의 최고점에는 반영하지 않습니다. 두 영역이 섞인 결과를 한쪽 기록으로 남기면 의미가 흐려지기 때문입니다.

## 입력 규칙

빈 입력(그냥 Enter)의 의미는 화면에 따라 다릅니다.

- **신규 입력**(퀴즈 추가, 메뉴 선택, 정답 입력 등) — 빈 입력은 잘못된 입력으로 보고 안내 후 다시 받습니다.
- **수정 화면** — 빈 입력은 "해당 항목을 기존 값으로 유지"를 뜻합니다. 바꾸려는 항목만 입력하면 됩니다.

## 파일 구조

```
codyssey-e1-2/
├── main.py                 # 엔트리포인트: 저장소를 만들어 QuizGame에 주입하고 실행
├── state.json              # 런타임 생성물 (gitignore, 첫 실행 시 자동 생성)
├── pyproject.toml          # 프로젝트 메타데이터 (dependencies 없음)
├── README.md
├── .gitignore
├── docs/screenshots/       # 실행 결과 스크린샷
└── app/
    ├── constants.py        # 공유 상수 (경로, 카테고리, 점수 규칙 등)
    ├── game.py             # QuizGame: 메뉴 루프와 기능 분배, 조립 지점
    ├── models/
    │   ├── quiz.py         # Quiz: 문제·선택지·정답·힌트·카테고리, 검증
    │   └── score.py        # ScoreRecord, ScoreBoard: 기록과 최고 점수
    ├── features/
    │   ├── play.py         # 출제·채점 로직 (PlaySession)
    │   ├── catalog.py      # 추가·수정·삭제·목록 (QuizCatalog)
    │   └── score.py        # 최고점 갱신·기록 (ScoreService)
    ├── storage/
    │   ├── repository.py   # StateRepository: state.json 로드/저장/복구
    │   └── defaults.py     # 기본 퀴즈 데이터
    └── cli/
        ├── prompts.py      # 입력 검증 (read_int 등), 안전 종료 예외
        └── views.py        # 화면 출력 문자열 생성
```

역할별로 계층을 나눴습니다. `models`는 다른 계층에 의존하지 않는 순수 데이터, `features`는 도메인 로직, `cli`는 입출력만 담당하고, `game.py`가 이들을 조립합니다. 저장 시점은 `game.py`가 각 메뉴 처리 끝에서 결정합니다.

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트의 `state.json` (UTF-8 인코딩)
- **역할**: 퀴즈 목록과 점수 데이터를 저장해, 프로그램을 종료한 뒤에도 유지합니다.
- **생성**: 첫 실행 시 파일이 없으면 기본 데이터로 시작하고, 종료할 때 생성됩니다. gitignore 대상이라 저장소에는 올라가지 않습니다.
- **안전 저장**: 임시 파일(`state.json.tmp`)에 먼저 쓰고 교체하므로, 저장 도중 중단돼도 기존 파일이 깨지지 않습니다.
- **손상 복구**: 파일이 깨졌거나 형식이 어긋나면 안내 후 기본 데이터로 복구합니다.

스키마:

```json
{
  "quizzes": [
    {
      "question": "리스트와 튜플의 가장 큰 차이는?",
      "choices": ["...", "...", "...", "..."],
      "answer": 3,
      "hint": "하나는 만든 뒤에 내용을 바꿀 수 없다",
      "category": "python"
    }
  ],
  "best_score": 100,
  "best_by_category": { "python": 80, "backend": 100 },
  "history": [
    {
      "played_at": "2026-07-31T21:40:12",
      "category": "python",
      "total": 5,
      "correct": 4,
      "score": 80,
      "hints_used": 1
    }
  ]
}
```

| 키 | 설명 |
| --- | --- |
| `quizzes` | 퀴즈 목록. 각 문항은 문제, 선택지 4개, 정답(1~4), 힌트(없으면 `null`), 카테고리를 가집니다. |
| `best_score` | 전체 최고 점수. |
| `best_by_category` | 카테고리별 최고 점수. |
| `history` | 최근 회차 기록(최대 50건 보관). |
