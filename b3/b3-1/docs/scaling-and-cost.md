# Scaling and Cost

현재 구성은 단일 인스턴스입니다. 트래픽이 늘어날 때의 점검 방법과 확장 기준, 비용 관리 방법을 정리했습니다.

## 현재 구조의 한계

```text
사용자 → DNS → EC2 1대 → 호스트 Nginx → 컨테이너 1개
```

| 항목 | 한계 |
|---|---|
| 가용성 | 인스턴스 장애 시 전체 중단 |
| 확장성 | 수직 확장만 가능 |
| 배포 | 재배포 중 짧은 중단 발생 |
| 가용 영역 | 단일 AZ |

## 병목 점검

### 지표 수집

```bash
# CPU, 메모리, 로드
top -b -n 1 | head -15
free -m
uptime

# 디스크
df -h
iostat -x 1 3

# 연결 상태
ss -s
ss -tan state established | wc -l
```

### 응답 시간 측정

```bash
curl -o /dev/null -s -w \
  'dns:%{time_namelookup} connect:%{time_connect} tls:%{time_appconnect} ttfb:%{time_starttransfer} total:%{time_total}\n' \
  https://b0e2-b3.ddns.net/
```

### 판단 기준

| 지표 | 확인 값 | 해석 |
|---|---|---|
| CPU 사용률 | 지속 70% 이상 | 인스턴스 타입 상향 검토 |
| 메모리 여유 | 지속 부족 | 메모리 중심 타입 검토 |
| TTFB | 증가 추세 | 애플리케이션 또는 프록시 병목 |
| 5xx 비율 | 증가 | 컨테이너 상태와 로그 확인 |
| CPU 크레딧 | 소진 | 버스트 성능 한계 도달 |

t3 계열은 CPU 크레딧을 사용하므로 크레딧 소진 시 성능이 떨어집니다. CloudWatch의 `CPUCreditBalance` 를 함께 확인합니다.

## 확장 단계

### 1단계: 수직 확장

가장 간단한 방법입니다. 인스턴스 타입을 상향합니다. 중단이 발생하고 단일 장애점은 그대로 남습니다.

### 2단계: Application Load Balancer 도입

다음 조건 중 하나라도 해당하면 ALB를 검토합니다.

- 인스턴스를 2대 이상 운영해야 한다
- 무중단 배포가 필요하다
- 장애 인스턴스를 자동으로 제외해야 한다
- TLS 종료를 인스턴스에서 분리하고 싶다
- 다중 가용 영역 구성이 필요하다

```text
사용자 → ALB → 대상 그룹 → EC2 여러 대
                 ↑
            /health 로 상태 확인
```

ALB를 도입하면 인증서를 ACM으로 옮기고, `/health` 를 대상 그룹 상태 검사 경로로 사용합니다.

### 3단계: Auto Scaling

지표 기반으로 인스턴스 수를 조정합니다. 시작 템플릿에 `scripts/provision.sh` 를 사용하면 동일한 구성으로 확장됩니다.

### 확장 시 비용 비교

| 구성 | 추가 비용 요소 |
|---|---|
| 단일 EC2 | 인스턴스, EBS |
| ALB 추가 | 시간당 요금과 LCU 요금, 프리티어 대상 아님 |
| Auto Scaling | 인스턴스 수만큼 비용 증가 |
| 다중 AZ | AZ 간 데이터 전송 비용 |

ALB는 프리티어 범위를 벗어나므로 실습 환경에서는 필요할 때만 생성하고 사용 후 삭제합니다.

## 비용 관리

### 예산 알림

`Billing and Cost Management → Budgets` 에서 월 예산을 설정하고 임계값 알림을 등록합니다. 프리티어 실습에서는 소액 기준으로 설정해도 충분합니다.

### 비용 추적

- `비용 탐색기` 에서 일별 비용 추이 확인
- `프리 티어` 페이지에서 사용량 비율 확인
- `Project` 태그를 비용 할당 태그로 활성화해 프로젝트별 비용 분리

### 비용이 발생하기 쉬운 지점

| 항목 | 주의점 |
|---|---|
| 미사용 EBS 볼륨 | 인스턴스를 종료해도 남는 경우가 있음 |
| 미연결 탄력적 IP | 연결되지 않은 상태에서 과금 |
| NAT 게이트웨이 | 시간당 요금과 데이터 처리 요금 |
| 로드 밸런서 | 트래픽이 없어도 시간당 요금 |
| 스냅샷 | 누적 저장 비용 |

### 실습 후 정리

평가와 증빙 확인이 끝나면 `docs/cleanup-checklist.md` 절차에 따라 리소스를 삭제하고, 다음 날 비용 탐색기에서 비용이 발생하지 않는지 확인합니다.
